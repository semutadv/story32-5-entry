A whole story in 32 characters, written for the make.fun bounty of
that name, in the form of a Wi-Fi network name. The name is thirty
characters long and contains everything a novel needs: parents, an
expectation, a rebellion, and a network the neighbours can read.
Somebody is dropping out of law school. The router announced it.

## Running it

`node main.ts` clears the output directory's contents and writes the
name to `/output/entry.txt` as plain UTF-8 text.
